# 實機驗收案例

CI 可驗證程式、引導狀態與輸出格式；相機、曝光、鏡像與不同膚色必須在實體 iPhone 驗收。

| 案例 | 操作 | 預期 |
|---|---|---|
| 正常拍攝 | 單張正臉位於框中，光線適合，保持不動 | 穩定 0.6 秒後倒數 1 秒，自動拍照，進入確認畫面 |
| 新版版面 | 在較小與較大 iPhone 開啟拍攝 | 黑底、三個圓形狀態、大橢圓預覽與雙行提示互不重疊，返回按鈕可取消；無語音按鈕 |
| 同時狀態 | 臉太遠但光線與角度適合；再同時轉頭並遮暗 | 前者呈現光線／角度綠、大小紅；後者各項依當下量測更新，不只顯示第一個失敗條件 |
| 臉大小範圍 | 逐步靠近與遠離，檢查預覽中偵測臉框高度占橢圓引導框高度的比例 | 低於 55% 為大小紅／距離太遠；55～80% 為大小綠；高於 80% 為大小紅／距離太近，大小不合格時不拍照 |
| 框與尺寸對齊 | 偵測臉框占橢圓框高度約 75% | 大小綠且其他條件適合時可以穩定並倒數，不要求把臉貼滿外框；輸出 JPEG 維持完整影像 |
| 門檻與縮放分離 | 修改大小門檻後，以同一影像比較預覽 | 預覽大小不變，僅合格距離範圍改變；燈號、提示與快門判定一致 |
| Demo 微調 | 首頁點「調整」，設定大小 55～75%，套用後拍攝 | 首頁顯示新範圍，下一次拍攝依新門檻判定；可同時調整亮度 |
| 設定取消與還原 | 修改大小後關閉視窗；再次修改並恢復預設、套用 | 取消保留先前已套用值；恢復後大小為 55～80%、亮度 50～170；下限等於上限時禁止套用 |
| 轉頭與追蹤 | 正臉後短暫轉頭，再回到正臉 | 有效觀測或追蹤區域存在時，光線與大小依當下影像更新，角度紅；姿態不可靠時停止倒數、不拍照，恢復後重新穩定 |
| 目標角度 | Demo 分別設定 45°／−45°／30°，容差 ±10°，套用後從正面緩慢左右轉頭 | 首頁顯示已套用目標；正面與相反方向角度紅，不拍照；目標附近且其他條件合格才能穩定、倒數、拍照，失效時立即暫停 |
| 左臉頰方向校正 | 標記受拍者左臉頰，讓鼻子轉向自己的右邊，使鏡頭拍到左臉頰，記錄目前度數正負；再測右臉頰 | 記錄左右臉頰對應的 Vision yaw 正負；目前未驗證，不以自拍預覽左右直接命名 |
| 側臉端正與信心 | 達到目標轉頭角度後抬頭、歪頭或遮擋 | 超出容差或姿態不可靠時禁止拍照；仍可取得臉框時，光線與大小保持當下量測 |
| 角度設定取消與還原 | 修改目標角度與容差後關閉；再次修改、恢復預設、套用 | 關閉不保存；還原目標 0°、容差約 ±17.2°，亮度與大小一併還原 |
| 待辨識 | 遮住鏡頭、離開畫面、追蹤失敗或超過 2 秒 | 灰色附「待辨識」，提示暫時無法辨識人臉，不使用上一刻綠色結果拍照 |
| 預覽與照片 | 完成拍攝並查看確認照片及回傳資料 | 拍攝畫面為橢圓預覽；確認與回傳 JPEG 為完整照片，不套用橢圓裁切 |
| 輕微手晃 | 倒數時小幅左右移動手機 | 輕微晃動可繼續；短暫超標會暫停，0.35 秒內恢復接續原倒數，暫停期間不拍照 |
| 短暫光線波動 | 倒數時短暫改變照明，再於 0.35 秒內恢復 | 保留倒數進度；恢復亮度條件後繼續，不在不合格亮度下拍照 |
| 臉部引導 | 靠近、遠離、偏離中心、轉頭、傾斜 | 顯示對應引導，不拍照 |
| 多人或無臉 | 移出畫面或加入第二個人 | 顯示對應提示並取消倒數 |
| 光線 | 暗室、過亮環境、普通室內；調整 Demo 門檻 | 過暗／過亮阻止倒數；回到範圍後重新開始 |
| 倒數中失效 | 轉頭或亮度超標持續超過 0.35 秒；移出畫面、遮住鏡頭 | 持續失效時歸零，無臉立即歸零；恢復後重新穩定與倒數 |
| 確認與重拍 | 拍照後重拍，再確認第二張 | 第一次不回傳，確認後只回傳第二張一次 |
| 方向與鏡像 | 拍攝「ABC 123」文字與左右不對稱物件，依序檢查自拍預覽、拍完確認畫面、Demo 首頁與回傳 JPEG | 預覽鏡像；確認畫面、首頁與回傳 JPEG 文字可正常閱讀且左右一致、正向、不鏡像；記錄出錯階段、TestFlight build、機型及 iOS 版本 |
| 權限拒絕 | 首次拒絕，開啟設定後允許，再按重試 | 顯示說明；允許後可拍照；取消時回傳 permission_denied |
| 取消與重複呼叫 | 取消拍攝；拍攝中再次呼叫；完成後再拍 | 取消回傳 null；重複呼叫回傳錯誤；下一次可正常拍攝 |
| 背景與中斷 | 倒數中切到背景／鎖定手機／相機被占用 | 相機停止、不使用舊畫面拍照；返回時重新引導或提供重試 |
| 膚色與機型 | 至少兩款 iPhone，搭配不同膚色與室內／自然光 | 記錄誤阻擋與漏判，必要時調整預設門檻 |

基本平均亮度無法完整攔截局部反光、側光、偏色或彩妝；這些情境應記錄為後續需求或與檢測 API 團隊共同定義。
